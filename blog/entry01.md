# Entry 1: Fantasy Game 
##### 11/14/26

## Content 
My goal was to make a fantasy game with multiple levels where the user goes on an adventure and has to pick different choices, similar to the CYOA project I did in SEP10.  I really enjoyed this project because it allowed me to use my own imagination and think of different choices for the user to pick. Since, I loved the fantasy genre so much, I decided to combine the two. Now, the tool I originally picked was [phaser.io](https://phaser.io/) because I loved how you had the option to describe your game and plan it out,  by talking to a "bot" in the app. However, I decided to change my tool and decided on [kaboom.js](https://kaboomjs.com/#add).


When I first started looking through the `phaser` website, I was a bit confused about where to start tinkering and coding. So, I had to look through a lot of tutorials in order to understand how to start creating my own mini game. Eventually, I was able to learn how by using `const game = new Phaser.Game(config)`  ,  but then my game wasn't working in my IDE and I didn't know why. The next day, after refreshing my browser, I was able to get it to work and learn how to change the background color of my game. However, after this struggle, I decided to try `kaboom` because `phaser` was just too confusing and there were too many problems I had to solve. While exploring the kaboom website, I learned it was very straightforward. There were tutorials on how to start my game and what code to use, along with little descriptions about the function of the code. These directions made it much easier for me to build my game and create a circle avatar as a starting point. I also learned how to change the position of my avatar and learning how to change the positton of it. For instance, the smaller the x-value gets in pos(x,y) the more my circle moves to the left, and the bigger it gets, the more it moves to the right. 


## EDP
A few months ago, I was in the first stage of the engineering design process, which was to  brainstorm an app or game idea. Then  choose a tool and tinker with it to see if that's what you want to use to create your game. I chose to make a game which was an adventure fantasy game where people had to choose between options in order to continue on their journey. Now, I am currently in the second stage which is to finalize my tool and pick which one I want to create my game with. I started off with [phaser.io](https://phaser.io/) but switched to [kaboom.js](https://kaboomjs.com/#add). Since most of my classmates are also doing kaboom, I have a lot of resources to go to if I ever need help. 

## Skills

Throughout the first and second stage of the engineering design process, I have learned two major skills, **Debugging** and **Organization**.

#### Debugging

When I first started tinkering with phaser, there was a lot of confusion because after adding code into my `game.js` file in my  IDE and creating my mini-game it wouldn't appear in my browser. First, I tried refreshing the browser and it still didn't work. Then I scanned my code for any errors and realized that my brackets weren't indented correctly, they weren't in the right place, and some opening brackets were missing closing brackets.  Even after fixing all of these brackets, that wasn't the problem, so I waited until the next day to see if my game would operate and it did. My next step, was a similar command which was changing my background color from blue to red in my game. When that didn't work,  I got really frustrated. I experimented and decided to input the hexadecimal color code for blue instead of just the word `blue`.  I learned how important it is to experiment with your code in order to fix any problems that might stop your code from working. 

#### Organization 
In my IDE, inside my tool folder I had two folders for phaser with a bunch of files that I downloaded from the app. Since It was a lot to keep track of, I decided to do some research and a person said to keep the folder with the  `game.js` file, so that's what I did. Then when I switched to Kaboom I decided to make a separate folder inside of my tool folder  deleted one of the folders because I didn't need those specifically.  I changed my tool from phaser to kaboom, I had a lot of files in my IDE from phaser. So I decided to create a separate folder for my kaboom code and created a seperate index.html file inside so that I don't get confused with the index.html I used for phaser that's outside of my phaser folder. Overall, I learned that you need to be organized with all your tinkering files and folders, so you know exactly where to go and what to look for. 

## Summary
In summary, I am very excited to explore kaboom more and start planning what elements to use in order to start creating my fantasy game.
