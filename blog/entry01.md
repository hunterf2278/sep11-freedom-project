# Entry 1: Fantasy Game 
##### 11/14/26

## Content 
My goal was to make a fantasy game with multiple levels where the user goes on an adventure and has to pick different choices, similar to the CYOA project I did in SEP10.  I really enjoyed this project because it allowed me to use my own imagination and think of different choices for the user to pick. Since, I loved the fantasy genre so much, I decided to combine the two. Now, the tool I originally picked was [phaser.io](https://phaser.io/) because I loved how you had the option to describe your game and plan it out,  by talking to a "bot" in the app. However, I decided to change my tool and decided on [kaboom.js](https://kaboomjs.com/#add).


When I first started looking through the `phaser` website, I was a bit confused about where to start tinkering and coding. So, I had to look through a lot of tutorials in order to understand how to start creating my own mini game. Eventually, I was able to learn how by using 'const game = new Phaser.Game(config)` ,   but then my game wasn't working in my IDE and I didn't know why. I looked through more videos but they were still very confusing, luckily, I was able to get it to work and learn how to change the background color of my game. After all of this struggling, I decided to try `kaboom` because `phaser` was just too confusing. While exploring the kaboom website, I learned it was very straightforward. There were tutorials on how to start my game and what code to use, along with little descriptions about the function of the code. These directions made it much easier for me to build my game and create a circle avatar as a starting point. I also learned how to change the position of my avatar and learning how to change the positton of it. For instance, the smaller the x-value gets in pos(x,y) the more my circle moves to the left, and the bigger it gets, the more it moves to the right. 


## EDP
A few months ago, I was in the first stage of the engineering design process, which was to  brainstorm an app or game idea. Then  choose a tool and tinker with it to see if that's what you want to use to create your game. I chose to make a game which was an adventure fantasy game where people had to choose between options in order to continue on their journey. Now, I am currently in the second stage which is to finalize my tool and pick which one I want to create my game with. I started off with [phaser.io](https://phaser.io/) but switched to [kaboom.js](https://kaboomjs.com/#add). Since most of my classmates are also doing kaboom, I have a lot of resources to go to if I ever need help.
